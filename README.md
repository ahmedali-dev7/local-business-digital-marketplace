# 🏪 LocalLane

### Good things are closer than you think.

**LocalLane** is a local business marketplace prototype designed to help people discover neighbourhood shops, explore products, and connect with small businesses through a simple, user-friendly web experience.

🌐 **Live Website:** [locallane.netlify.app](https://locallane.netlify.app)

---

## ✨ Features

- 🔎 **Search:** Find local shops and products by name, type, or location.
- 🏬 **Discover Local Shops:** Explore neighbourhood businesses through shop listings.
- 🛍️ **Product Browsing:** View products, prices, and their associated shops.
- 🛒 **Shopping Cart:** Add products, change quantities, remove items, and view totals.
- 🤝 **Vendor Registration:** Submit a business listing through the registration form.
- 📱 **Responsive Design:** A clean interface designed for a range of screen sizes.
- 💾 **Browser Storage:** Vendor listings and cart-related data can be stored locally in the browser.

## 🛠️ Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Languages:** JavaScript, HTML, CSS
- **Deployment:** Netlify
- **Version Control:** Git and GitHub

## 🚀 Run Locally

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ahmedali-dev7/local-business-digital-marketplace.git
   ```

2. Open the project folder:

   ```bash
   cd local-business-digital-marketplace/frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To generate the production build, run:

```bash
npm run build
```

The generated files will be available in the `dist` directory.

## 📌 Project Status

LocalLane is a **frontend prototype**. The shop and product listings currently include sample data, and browser-stored information is specific to the browser or device being used.

A shared database, real user authentication, online payments, and synchronised listings across devices are not currently implemented.
